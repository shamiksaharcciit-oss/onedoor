The receipt is the hero

  • One receipt per screen; verification state is the loudest element.
  • Digests always full-width mono, never truncated in the chain block.
  • Semantic green/red never doubles as brand accent; the seal gold does not signal state.

The X-11 of UIs

  • Every displayed value is read from a verified artifact — the viewer runs the same verification as the CLI and renders its output.
  • The UI cannot show a number the store doesn't back.
  • Sample or synthetic data is labelled in-frame, always.

Scope fence

  • Static HTML generated from the store; read-only; no backend, no auth.
  • Live tail = tailing the append-only ledger; new receipts append, nothing mutates.
  • No dashboards, no charts-over-time, no filters. One job: make a single receipt checkable.
