## 1. Clause 1 — "trailing ASCII whitespace, byte-level" — CONFORMED

The preimage is computed as `raw[:footer_start].rstrip() + b"\n"` where `raw` is
**bytes**, so `bytes.rstrip()` removes exactly ` \t\n\r\f\v` and never consults the
Unicode database. Verified rather than read: a body ending in **U+00A0** survives
into the preimage intact (`str.rstrip()` would have eaten it, and the probe asserts
that it would, so the test cannot pass vacuously). Regression test added.

## 2. Clause 2 — "the footer line is the end of the file" — DIVERGED, twice

The verifier parsed the footer as `raw[start:].rstrip(b"\r\n")`. That silently
tolerated **any number of trailing CR/LF bytes** after the footer's terminating LF.
Probed against the clause:

| File | Clause 2 requires | Verifier said |
|---|---|---|
| footer + one extra LF | malformed | **ok** |
| footer + a bare CR | malformed | **ok** |
| footer + arbitrary content | malformed | damaged ✓ |
| footer + NUL | malformed | damaged ✓ |
| trailing spaces after the digest | malformed | damaged ✓ |

Both divergences are in the **permissive** direction — precisely the failure your
clause names, where unattested content rides under a green verdict. They were found
by probing the clause, not by re-reading the code and agreeing with it.

## 3. Impact: none on the archive, which is why the direction is safe

Every memo delivery holds was checked for bytes after the footer's terminating LF:
**13 memos carry footers, 0 have trailing bytes.** No archived memo changes verdict
under the strict reading. This matches your statement that a divergence means the
checker, not the archive — and it is the fact that made the fix safe to apply.

## 4. What was done, and the one judgement call

Fixed: the verifier now requires the footer line's terminating LF to be the final
byte, and reports the byte count when it is not. Seven cases regression-tested,
including the canonical form, which must still verify.

**The judgement call, stated because it is yours to overrule.** Your instruction was
"an escalation to core, not a quiet fix". Delivery read *quiet* as the operative word

## 5. A regression the fix caused, found and closed

Adding the trailing-byte check moved CRLF-corrupted files onto a **new branch**,

tighten conformance. The hint now attaches to the **outcome** rather than to one
route, so it survives the next new branch. Caught by an existing test asserting the
